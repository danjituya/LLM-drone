一、文件夹作用说明
本文件夹存放本参赛作品团队自主开发的全部源代码、工程设计文件、模型文件、数据集典型样本，
为作品的核心源码工程目录，所有代码均为团队自主开发完成，无抄袭侵权内容。

三、环境要求
1.  操作系统：Windows 10/11、Linux、macOS 均可兼容
2.  Python版本：3.9 ~ 3.11（推荐Python 3.10，兼容性最佳）
3.  硬件要求：
    - 基础运行：CPU即可运行所有核心功能
    - 模型训练/高性能识别：推荐NVIDIA显卡（4GB以上显存），支持CUDA加速
4.  网络要求：可正常访问互联网，用于大语言模型API调用

四、运行部署步骤
1.  环境安装
    打开命令行，进入本文件夹根目录，执行以下命令安装Python依赖：
    pip install -r requirements.txt

2.  模型准备
    按照「04-模型文件/模型文件说明.txt」的指引，下载best.pt权重文件，放入「04-模型文件」文件夹内

3.  启动系统
    进入「01-后端核心源码」文件夹，执行以下命令启动后端服务：
    python app.py

4.  访问系统
    服务启动成功后，打开浏览器访问以下地址即可进入系统：
    http://127.0.0.1:54321

五、核心功能说明
1.  自然语言交互：支持用户通过自然语言下达巡检指令，无需专业操作即可完成全流程巡检
2.  多无人机集群调度：自动分配巡检区域，规划最优蛇形巡检路径，支持多无人机协同作业
3.  病虫害智能识别：基于YOLO深度学习模型，实现农田作物病虫害的实时识别、分类与统计
4.  可视化驾驶舱：多维度数据可视化展示，包含巡检路径、病害分布热力图、病害类型统计等
5.  巡检报告自动生成：自动生成标准化巡检分析报告，支持导出与在线查看
